# Инструкция по обновлению версии NetFix

При выпуске новой версии приложения необходимо обновить версию в следующих файлах:

## 1. NetFix.csproj
**Путь:** `NetFix.csproj`

Измени три строки с версией:
```xml
<Version>1.0.8</Version>
<AssemblyVersion>1.0.8.0</AssemblyVersion>
<FileVersion>1.0.8.0</FileVersion>
Например, для версии 1.0.9:

<Version>1.0.9</Version>
<AssemblyVersion>1.0.9.0</AssemblyVersion>
<FileVersion>1.0.9.0</FileVersion>
Что это даёт:

Версия в свойствах .exe файла
Автоматическое отображение версии в трей меню (через AppVersion.cs)
Версия в метаданных сборки
2. NetFix_Setup (6).iss
Путь: NetFix_Setup (6).iss

Измени две строки:

AppVersion=1.0.8
OutputBaseFilename=NetFix_Setup_v1.0.8
Например, для версии 1.0.9:

AppVersion=1.0.9
OutputBaseFilename=NetFix_Setup_v1.0.9
Что это даёт:

Версия в установщике Inno Setup
Правильное имя файла установщика (NetFix_Setup_v1.0.9.exe)
3. README.md
Путь: README.md

Найди строку в самом низу файла:

<sub>v1.0.8 · 2026</sub>
Измени на новую версию:

<sub>v1.0.9 · 2026</sub>
Что это даёт:

Актуальная версия в документации на GitHub
Итого: 3 файла для изменения
NetFix.csproj — 3 строки (Version, AssemblyVersion, FileVersion)
NetFix_Setup (6).iss — 2 строки (AppVersion, OutputBaseFilename)
README.md — 1 строка (версия в футере)
После изменения версии:

Пересобери проект (dotnet build)
Создай установщик через Inno Setup
Закоммить изменения в git с сообщением типа "Bump version to 1.0.9"
Примечание
Файл app.manifest содержит version="1.0.0.0" в assemblyIdentity, но его не нужно менять — это техническая версия манифеста, не версия приложения. ```
