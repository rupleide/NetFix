  КАК СОЗДАТЬ ТРЕК ДЛЯ NETFIX
═══════════════════════════════════════════════════════════════════

1. СОЗДАЙ ПАПКУ С НАЗВАНИЕМ ТРЕКА
   Например: NetFix_Beat_01

2. ДОБАВЬ ФАЙЛЫ:
   
   📄 notes.json (обязательно)
   {
     "Title": "NetFix Beat 01",
     "Author": "rupleide",
     "TrackFile": "track.mp3",
     "Bpm": 140,
     "Notes": [
       { "Time": 1.0, "Lane": 0 },
       { "Time": 1.5, "Lane": 1 },
       { "Time": 2.0, "Lane": 2 },
       { "Time": 2.5, "Lane": 3 }
     ]
   }
   
   🎵 track.mp3 (обязательно)
   Твой аудиофайл
   
   🖼️ cover.png (опционально)
   Обложка трека 300x300px

3. УПАКУЙ В ZIP
   NetFix_Beat_01.zip
   └── NetFix_Beat_01/
       ├── notes.json
       ├── track.mp3
       └── cover.png (опционально)

4. ПОМЕСТИ В ПАПКУ Tracks/
   NetFix/Tracks/NetFix_Beat_01.zip

5. ГОТОВО!
   Трек автоматически появится в игре в разделе "ТРЕКИ NETFIX"

═══════════════════════════════════════════════════════════════════
  ПОЛЯ notes.json
═══════════════════════════════════════════════════════════════════

Title      - Название трека (отображается в меню)
Author     - Автор трека
TrackFile  - Имя mp3 файла (обычно "track.mp3")
Bpm        - Темп в ударах в минуту (влияет на скорость нот)
Notes      - Массив нот:
  Time     - Время ноты в секундах от начала трека
  Lane     - Дорожка (0=Left/A, 1=Down/S, 2=Up/W, 3=Right/D)

═══════════════════════════════════════════════════════════════════
  СОВЕТЫ ПО СОЗДАНИЮ КАРТ
═══════════════════════════════════════════════════════════════════

• Используй редактор в игре (кнопка "Редактор")
• Начинай с простых паттернов
• Тестируй карту перед публикацией
• BPM должен соответствовать реальному темпу трека
• Первая нота обычно на 1-2 секунде (даёт время подготовиться)
• Избегай слишком быстрых последовательностей для новичков
