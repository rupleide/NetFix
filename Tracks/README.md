# NetFix Built-in Tracks

Эта папка содержит встроенные треки для ритм-игры NetFix.

## Структура трека

Каждый трек должен быть упакован в `.zip` архив со следующей структурой:

```
TrackName/
├── notes.json      ← Карта нот (обязательно)
├── track.mp3       ← Аудиофайл (обязательно)
└── cover.png       ← Обложка трека (опционально)
```

### notes.json

```json
{
  "Title": "NetFix Beat 01",
  "Author": "rupleide",
  "TrackFile": "track.mp3",
  "Bpm": 140,
  "Notes": [
    { "Time": 1.0, "Lane": 0 },
    { "Time": 1.5, "Lane": 1 },
    { "Time": 2.0, "Lane": 2 }
  ]
}
```

**Поля:**
- `Title` — название трека
- `Author` — автор
- `TrackFile` — имя mp3 файла (обычно `track.mp3`)
- `Bpm` — темп трека (ударов в минуту)
- `Notes` — массив нот
  - `Time` — время ноты в секундах
  - `Lane` — дорожка (0-3): 0=Left, 1=Down, 2=Up, 3=Right

## Добавление нового трека

1. Создай папку с названием трека
2. Добавь `notes.json` и `track.mp3`
3. Упакуй в `.zip` архив
4. Помести `.zip` в эту папку (`Tracks/`)
5. Трек автоматически появится в разделе "Треки NetFix"

## Примеры

- `NetFix_Beat_01.zip` — базовый трек для новичков
- `NetFix_Beat_02.zip` — средняя сложность
- `NetFix_Beat_03.zip` — продвинутый уровень
